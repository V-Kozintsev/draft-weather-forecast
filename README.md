# Atmos — погода в деталях

[Открыть приложение →](https://v-kozintsev.github.io/atmos-weather/)

[Скачать для Windows](https://github.com/V-Kozintsev/atmos-weather/releases/download/v2.1.0/Atmos-Setup-2.1.0-x64.exe) · [Без установки](https://github.com/V-Kozintsev/atmos-weather/releases/download/v2.1.0/Atmos-Portable-2.1.0-x64.exe)

Погодная панель, с которой можно строить планы: сейчас, следующие 24 часа и неделя впереди.

- Интерактивный SVG-график температуры, осадков и ветра; выбор дня и часа.
- Поиск городов с клавиатурной навигацией, геолокация по запросу, избранное и ссылки на прогноз.
- Качество воздуха, УФ-индекс, восход и закат. Подбор дневного часа для прогулки, бега и велосипеда по прозрачным правилам.
- Подбор одежды для ближайшего часа и до конца дня: женский или мужской образ, полный комплект по категориям, повседневный/офисный/активный стиль и настройка чувствительности к холоду.
- Реальные данные Open-Meteo; отмена устаревших запросов, тайм-ауты, независимая загрузка качества воздуха и сохранённый прогноз при сбое сети.
- Адаптивный интерфейс, локальные шрифты, доступные состояния и поддержка reduced motion.
- Устанавливаемое PWA: отдельное окно, иконка приложения, офлайн-интерфейс и обновления по подтверждению.
- Windows-приложение на Electron: локальный интерфейс, сворачивание в область уведомлений, мини-погода поверх окон и текущая температура в подсказке значка.
- Мобильные проекты Android и iOS на Capacitor: тот же интерфейс и геолокация по нажатию через системное разрешение.

**React · TypeScript · Vite · PWA / Workbox · SVG · REST API · Vitest**

## Как установить

**Windows 10/11 (64 бит):** скачайте установщик или portable-версию по ссылкам выше. Закрытие окна сворачивает Atmos в область уведомлений; полное завершение — через меню значка. «Мини-погода» показывает компактную панель поверх других окон. Интерфейс включён в приложение, новый хостинг не нужен. Свежий прогноз загружается из Open-Meteo. Сборка пока без цифровой подписи.

[Мини-панель в браузере](https://v-kozintsev.github.io/atmos-weather/?view=mini) доступна без установки. Этот режим не закрепляет окно поверх других приложений.

Откройте приложение и нажмите «Установить». В Chrome и Edge также доступна установка из меню браузера. На iPhone/iPad: Safari → «Поделиться» → «На экран Домой».

После первого успешного запуска интерфейс доступен без сети. Последний прогноз сохраняется до суток и отмечается как сохранённый; для новых данных нужен интернет. Service worker сохраняет только ресурсы самого приложения, без запросов поиска и координат.

## Запуск

Node.js 22.18+ или 24+. Установка: `npm ci`. Разработка: `npm run dev`. Проверки: `npm test` и `npm run typecheck`. Сборка: `npm run build`; просмотр сборки: `npm run preview`.

Windows-приложение: `npm run desktop`; установщик и portable EXE: `npm run desktop:build`. В оболочке отключён доступ веб-интерфейса к Node.js; локальные файлы загружаются через ограниченный протокол, внешние HTTPS-ссылки открываются в браузере. Город в desktop-версии выбирается через поиск и избранное.

Мобильные проекты: `npm run mobile:sync` обновляет веб-ресурсы в `android/` и `ios/`. Android открывается через `npx cap open android`, iOS — через `npx cap open ios` на Mac с Xcode. Для локальной проверки Android можно собрать debug APK командой `cd android && ./gradlew assembleDebug`. Публикация в магазинах требует отдельной подписи, аккаунтов разработчика и проверки на устройствах.

Диагностика оболочки: запуск `Atmos.exe --diagnostics`. Префикс `[Atmos Desktop]`; пользовательские данные не выводятся. Аргумент `--background` запускает приложение сразу в области уведомлений. Windows-сборки публикуются из тегов `v*` через GitHub Actions.

API-ключи и отдельный сервер не нужны. [Open-Meteo](https://open-meteo.com/) предоставляет бесплатный API для некоммерческого использования; для коммерческого размещения необходимо проверить его условия. Погодные данные распространяются по [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), качество воздуха — Open-Meteo / CAMS. Время отображается в часовом поясе выбранного города. Геолокация округляется до 0,01° и передаётся Open-Meteo только по нажатию «Где я». Избранное и последний прогноз хранятся в браузере; сохранённые данные явно отмечены и используются не дольше суток.

Стиль и чувствительность к холоду сохраняются только на устройстве. В приложении нет рекламы, партнёрских ссылок и каталога товаров.

Диагностика API включается командой `localStorage.setItem('atmos-debug', 'true')` в консоли браузера. Префикс `[Atmos API]`; координаты и текст поиска не выводятся. Отключение: `localStorage.removeItem('atmos-debug')`.
